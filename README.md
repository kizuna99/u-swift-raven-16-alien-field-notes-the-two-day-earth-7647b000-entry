A tiny Node 22 TypeScript program (`main.ts`, standard library only) that writes
one line to `/output/entry.txt`: an alien tourist's review of planet Earth.

The line:

> Three stars — gorgeous oceans, baffling customs: each human trails a small wolf, reverently bagging its droppings as souvenirs; I shipped home twelve before anyone explained.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The review is 174 characters (176 bytes UTF-8), a single line — it passes the
competition gate (1–200 characters) and is judged pairwise by the house judge.
